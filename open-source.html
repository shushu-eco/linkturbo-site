Free and open source

No price, no licence key, no account. The code of the extension and of the full program is public. Here is what that means for you.

  1. 01

    Add it and record

    Add Link Lite to Chrome, Edge or Brave and press Record. There is no trial that runs out and nothing to enter.

  2. 02

    Read the code

    Everything Link does is in the open on GitHub: the extension, the Windows program, Link Night and this website.

Licence

What the licence allows

+

The GNU General Public License, version 3. You may use Link for anything, read its code, change it and pass it on. Whoever passes on a changed version must pass on its code under the same licence.

Before

Link Lite used to cost EUR 1.99

+

Until version 0.5.0 it worked for three recordings and then asked for a key. That is over: there is no trial, no key and no shop, and the skins are everybody’s.

Today

Until the store has the free version

+

The Chrome Web Store still hands out 0.4.3, which asks for a key after three recordings. Version 0.5.0 is in review. To have it today: download the code from GitHub, open chrome://extensions, switch on Developer mode, press Load unpacked and choose the folder named extension.

Privacy

Nothing to take on trust

+

The extension uploads nothing and makes no request of its own to any server. With the code public, anyone can check that.

Help

Found a problem, or want to help

+

Open an issue on GitHub or say it in Discord. Changes to the code are welcome as pull requests.

Contact

Who to write to
