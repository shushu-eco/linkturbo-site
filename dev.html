See it work

What DevTools makes you dig for, in plain sight.

ALREADY RECORDING

It failed before you opened F12

Link Dev records from the moment the page starts. When something breaks, press Alt+Shift+D: the request, the console error and the cookies are already there. No reload, no trying again.

CONSOLE

CORS errors, in plain words

Not just “blocked”: which header is missing, which preflight failed, or why * is not allowed with cookies.

ALLOW IN DEV

Blocked by CORS? See why, then allow it

One click, in development, adds the headers the API forgot, as a rule you can see and switch off.

GRAPHQL

200 OK. But it failed.

GraphQL hides its errors behind a 200. Link Dev names each call by its operation and counts a 200 with errors as failed, with the errors first.

MOCK

Test your error screens

Make any call answer what you want, in one click from the request: status, headers, body and delay.

MOCK SCRIPTS

Mocks that think

A few lines of JavaScript work out each answer from the call. They run in a sandbox, never in the page.

REDIRECT

Production calls, your localhost

Replace a part of any address, so the live site talks to the server on your own computer. Page loads too.

COPY AS

Copy as cURL, PowerShell, fetch, Python

Seven forms, made to run as they are, on Windows too: cURL for bash and cmd, PowerShell, fetch, Node.js, Python requests and HTTPie.

SECRETS

Share your screen. Not your tokens.

Tokens, cookies and passwords are hidden by default: on screen, in HAR files, reports and summaries. The eye shows them when you want.

What is in it

Three DevTools tabs, and the tools they never had.

NETWORK

Every request, kept

Status, headers, payload and response, kept across reloads. A badge counts the failed ones. Edit and resend, and export a HAR file or a summary for a ticket.

GRAPHQL

Calls named by their operation

query GetOrders, not just /graphql. A 200 with GraphQL errors counts as failed.

CONSOLE

The page's console, copied

Logs, uncaught errors and rejected promises, written the way DevTools writes them, and a line for every failed request.

APPLICATION

Cookies and storage

Cookies, local and session storage, IndexedDB and Cache storage: view, edit, add and delete.

RULES

One click from any request

Mock, Block, Delay, Redirect, or change headers. Each rule can be seen and switched off in Settings.

PRIVATE

Nothing leaves your browser

No account, no server, no analytics. It reads only the sites you turn on; local addresses are on from the start.

Three steps

Running in a minute. No account.

  1. INSTALL01 Add it to your browser Chrome, Edge or Brave, version 126 or newer. No account.
  2. OPEN02 Press Alt+Shift+D Or the Link Dev button. A window you put anywhere, or the side panel.
  3. TURN ON03 Your site, and nothing else Localhost works at once. On any other site, press Turn on for this site.

Nothing leaves your browser.

No account, no server, no analytics. Link Dev reads only the sites you turn on, keeps what it records in your browser, and hides your tokens on screen and in every file it saves.
