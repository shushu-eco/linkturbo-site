What's new

Every version, newest first.

  1. v0.4.3 2026-10-08

    Three recordings to try, then a key

    Link Lite works in full for your first three recordings, then asks for a licence key: EUR 1.99, once, in up to three browsers. Files saved from the rewind close together count as one try. On Twitch, Link waits for you to press Start Watching before it records. In the Chrome Web Store since 9 October 2026.

  2. v0.3.4 2026-10-08

    Marks for your editor, and theatre mode by itself

    A recording’s marks can be copied as a list or saved as a marker file for DaVinci Resolve. Link switches the site to theatre mode when you press Record, and back when the recording ends. Not released yet.

  3. v0.3.2 2026-10-08

    One panel, one file

    The panel is one fixed size that can be moved anywhere. A recording is a single mp4 with its marks inside, named after the channel and the time. A stream page that was already open no longer needs to be loaded again.
